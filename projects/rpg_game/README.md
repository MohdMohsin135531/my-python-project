# RPG Game

A text-based RPG game with character creation and stat visualization. Currently in progress.

## How to run

```bash
python rpg_game.py
```

## Features (so far)

- Character creation with name and class selection
- Stats system (HP, attack, defense, etc.)
- Visual stat bars using symbols
- Input validation throughout

## Planned

- Combat system
- Inventory and items
- Multiple enemies
- Save/load game state

## What I'm learning

- Object-oriented programming (classes and methods)
- Structuring a larger, multi-file project
- Game logic and state management
