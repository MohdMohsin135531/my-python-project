# Caesar Cipher

A CLI app that encrypts and decrypts text using the Caesar cipher — a substitution cipher that shifts letters by a given number.

## How to run

```bash
python caesar_cipher.py
```

## Features

- Encrypt any text with a chosen shift value
- Decrypt previously encrypted text
- Handles both uppercase and lowercase letters

## What I learned

- String manipulation and iteration
- Modular arithmetic for letter wrapping
- Debugging naming conflicts and type errors
