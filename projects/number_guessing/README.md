# Number Guessing Game

A CLI game where the computer picks a random number and you try to guess it. Tracks how many attempts it takes.

## How to run

```bash
python number_guessing.py
```

## Features

- Computer randomly selects a number
- Tells you if your guess is too high or too low
- Counts and displays number of attempts at the end

## What I learned

- Random number generation
- Loops and conditionals
- Tracking state with variables
