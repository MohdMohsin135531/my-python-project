# Bill Splitter

A CLI app that calculates how much each person owes when splitting a restaurant bill, including tip.

## How to run

```bash
python bill_splitter.py
```

## Features

- Enter total bill amount
- Choose tip percentage
- Split between any number of people
- Outputs each person's share

## What I learned

- Functions and return values
- User input and type conversion
- Basic arithmetic logic
