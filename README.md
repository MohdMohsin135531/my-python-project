# Python Projects

A collection of Python projects built while learning programming — progressing from basic scripts to OOP-based applications.

## Projects

| Project | Description | Status |
|---|---|---|
| [Bill Splitter](projects/bill_splitter/) | Splits a restaurant bill between people including tip | ✅ Complete |
| [Caesar Cipher](projects/caesar_cipher/) | Encrypts and decrypts text using the Caesar cipher algorithm | ✅ Complete |
| [Calculator](projects/calculator/) | CLI calculator for basic arithmetic operations | ✅ Complete |
| [Number Guessing](projects/number_guessing/) | Guess the number game with attempt tracking | ✅ Complete |
| [Password Analyzer](projects/password_analyzer/) | Analyzes password strength based on complexity rules | ✅ Complete |
| [RPG Game](projects/rpg_game/) | Text-based RPG with character creation | 🚧 In Progress |
